1. types of position properties- static(default), relative, absolute, fixed. sticky
  2. relative will let us use top, left, bottom, right props wrt. the original position while other elements stay wherever they are
  3. absolute will set the element to the nearest positioned element. here, if parent is not positioned, it'll go furhter up until it reaches the html tag
  4. fixed is as it is, it'll fix the element on whichever place specified
  5. sticky will attach the element to specified pos when scrolled (until element reaches -- referring to comparing box2 and box4 sticky position)
  6. NOTE:
    if properties transform, filter, perspective are used, then that parent will also be considered as a positioned element
