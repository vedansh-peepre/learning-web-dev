some metrics that are used to assess and give score of a website
Cumulative layout shift (CLS)
this is a value of how much the components of the website shifts while loading.
the main goal here is to prevent acciedental / unintended clicks due to the shift
Largest contextual paint (LCP)
it is the time to render / load the largest image or text block visible in the viewport.
the lesser, the better
good(less than 2.5s), average(less than 5s), poor(>5s)
First input delay (FID)
It is the time taken before the processing starts after a click.
the lesser the better, and for seo, it should be under 100ms
good(less than 100ms)

lighthouse is a tool that's used to generate a report of a website based on metrics listed above and beyond (more metrics)
it can be accessed through the dev tools of browser
