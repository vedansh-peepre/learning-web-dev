Notes:

  1. id is a unique attribute given to an element
  2. class is an attribute used to target a group of elements
  3. multiple elements can have the same class and an clement can have multiple classes
  4. if en element has multiple classes, then they're separated by a space
  5. but neither multiple elements have the same id, nor an element can have multiple ids
  6. CSS for class is targeted by ".", and for id, it's "#"
  7. CSS for id overwrites that of the class, even if css of class is written after that of id
  8. --
  9. moreover, id can be used to create links, just add #id_name after the link, and it'll pre-scroll to that id element
